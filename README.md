# **Tugas Slicing PWEB**

Website ini merupakan platform informasi tentang K-Pop girl group Hearts2Hearts (H2H). 
Di dalam website ini, kita dapat menjelajahi background grup, memperkenalkan 8 member melalui kartu profil dan biodata individu,
juga mengakses berbagai tautan media sosial resmi Hearts2Hearts.

Website ini dibuat menggunakan kombinasi HTML, CSS, dan JavaScript:

- **HTML**
  Menyusun struktur utama website secara semantik, mulai dari navigasi header, *hero banner*, deskripsi grup *About*, kotak kotak kartu 8 member, section profil per-orang *Member Profile*, hingga media sosial di bagian footer.

- **CSS**
  Mengatur estetika bernuansa cerah dan juga tampil responsif di laptop maupun HP. Digunakan juga untuk memberikan bingkai (*stroke*) pada foto member, efek tombol *hover*, dan transisi pada halaman.

- **JavaScript**
  Digunakan untuk manipulasi konten secara dinamis tanpa *reload* halaman, seperti:
  - **Profil Interaktif:** Mengubah foto, nama, *role*, dan paragraf biodata di section *Member Profile* secara otomatis saat tombol nama atau kartu member diklik.
  - **Navigasi Mobile:** Membuka dan menutup menu navigasi *dropdown* di layar HP.
  - **Efek Scroll & Animasi:** Memberikan efek *fade-out* pada *hero banner* dan membuat animasi *scroll reveal* saat halaman discroll ke bawah.
